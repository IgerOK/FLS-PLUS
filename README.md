# FLS-PLUS (Files Plus) v1.1

**FLS-PLUS** — программа для создания текстовых снимков файловых структур проектов с автоматическим определением кодировок (UTF-8 / CP1251).

## 📋 О программе

FLS-PLUS (Files Plus) — это инструмент для разработчиков и системных администраторов, позволяющий:

- Построить псевдографическое дерево файлов и папок
- Автоматически определить кодировку файлов (UTF-8 / CP1251)
- Свернуть проект в один текстовый файл-снимок
- Развернуть проект из снимка с сохранением структуры и кодировок

## 📥 Установка

### Требования
- **AutoHotkey v2.0** или выше ([скачать](https://www.autohotkey.com/))
- **Windows 7 / 8 / 10 / 11**

### Установка
1. Скачайте файл `FLS-PLUS.ahk`
2. Установите AutoHotkey v2.0
3. Запустите `FLS-PLUS.ahk` двойным щелчком

> **Примечание:** Программа не требует установки — достаточно запустить `.ahk` файл.

## 🎮 Использование

### Быстрый старт

1. **Выберите папку** — кнопка "📁 Обзор" или выпадающий список истории
2. **Дождитесь сканирования** — дерево построится автоматически (асинхронно, UI не зависает)
3. **Перейдите на вкладку "Свернуть"**
4. **Нажмите "📦 Свернуть"** — программа рассчитает размер и проверит свободное место
5. **Подтвердите сохранение**

### Для разворачивания:

1. **Перейдите на вкладку "Развернуть"**
2. **Выберите файл-снимок** и целевую папку
3. **Нажмите "📂 Развернуть"**

### Закладки

- **➕⭐** — добавить текущую папку в закладки
- **⭐** — открыть меню закладок

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F1` | Открыть справку |

## 📁 Формат снимка

Снимок сохраняется в текстовый файл с форматом:
```
=== путь/к/файлу | utf-8 ===
содержимое файла

=== путь/к/файлу | cp1251 ===
содержимое файла
```

Поддерживаемые кодировки: `utf-8`, `cp1251`

## ⚙️ Настройки

Все настройки сохраняются в файле `FLS-PLUS.ini` в папке со скриптом:

- Последняя выбранная папка
- История папок и файлов (до 20 записей)
- Закладки (до 15 записей)
- Размер и положение окна
- Активная вкладка
- Режим "Поверх всех"

## 🛠️ Технические детали

### Защита от ошибок
- **Глубокая рекурсия** — ограничение глубины сканирования (макс. 100 уровней)
- **Длинные пути** — проверка на превышение MAX_PATH (260 символов)
- **Одновременные операции** — блокировка повторного запуска
- **Нехватка места** — предварительная проверка свободного пространства
- **Безопасность путей** — экранирование спецсимволов для командной строки

### Оптимизация памяти
- Прямая запись в файл при сворачивании (без хранения в памяти)
- Асинхронное сканирование (не блокирует интерфейс)

## 📝 Известные ограничения

- Файлы размером >2 ГБ могут загружаться в память целиком при чтении
- Не поддерживаются пути длиннее 260 символов (ограничение Windows)
- Требуется AutoHotkey v2.0 (не совместимо с v1.x)
